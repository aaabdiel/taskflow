\# TaskFlow - MVP Gestor de Tareas



Aplicación web Full Stack para la gestión de tareas de un equipo. Desarrollada como prueba técnica.



\## Tecnologías Utilizadas



\*\*Frontend:\*\*

\- React + Vite + TypeScript

\- CSS puro (para un diseño responsive y ligero sin dependencias extra)



\*\*Backend:\*\*

\- Node.js + Express + TypeScript

\- Zod (Validación de esquemas y datos)

\- CORS (Manejo de políticas de origen cruzado)



\*\*Base de Datos:\*\*

\- SQLite (usando el módulo nativo `node:sqlite` integrado en Node.js)



\## Cómo ejecutar el proyecto localmente



El proyecto está dividido en dos carpetas: `backend` y `frontend`. Necesitarás dos terminales abiertas.



\### 1. Levantar el Backend

```bash

cd backend

npm install

npm run dev
